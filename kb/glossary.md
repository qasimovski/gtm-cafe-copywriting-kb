# Glossary — GTM Cafe #copywriting-feedback

Shorthand and named frameworks used in the channel, with the record where each appears.
Knowing these makes the thread files and pattern files readable.

## Channel-native terms

| Term | Meaning |
|---|---|
| **roast / rip it apart / wreck me** | The standard way to open a request for feedback. Signals you want blunt critique, not encouragement. "Please roast my copies" `[rec_20260625_abrar_hussain]` |
| **presumed personalization** | Kellen's term: fold the personal detail into the argument instead of announcing it up front. Opposite of "hey name — noticed x". Also called *understated personalization* `[rec_20260616_kyle_nelson]` |
| **open loop** | A deliberate gap the reply closes. Two accepted forms: "you are x + you want y" (loop = how) or "you are x, we do y-mechanism" (loop = what outcome) `[rec_20260813_barash]` |
| **sincere scarcity** | Stating a real constraint plainly rather than manufacturing FOMO `[rec_20260722_ivan]` |
| **empathetic friction / judo not headbutt** | Mick's phrase for disrupting the status quo without triggering defensiveness `[rec_20260811_mick]` |
| **inject dopamine** | Kellen on tone: change the reader's state before they realise they're reading a cold email `[rec_20260710_mikulas]` |
| **reply maxxxing** | Optimising purely for reply rate; the context for the "7th grade reading level" rule `[rec_20260811_mick]` |
| **brevity pilled** | Committed to short copy on the strength of data — Kellen describes himself this way, ranking Will Allred as more so `[rec_20260708_sharad]` |
| **cake** | Everything that isn't the offer; filler. "just lead with that. everything else is cake" `[rec_20260807_burhan_khaja]` |
| **low status** | Copy that circles the ask instead of stating it, reading as deferential. ben's critique term `[rec_20260807_burhan_khaja]` |
| **the wedge** | The narrow first thing you'd test or fix, offered instead of a full solution `[rec_20260625_abrar_hussain]` |
| **bump** | A short follow-up in the same thread that just asks what they thought `[rec_20260714_matt_sezgin]` |
| **blame infra** | Attributing weak results to deliverability/sending setup rather than copy — invoked as a check before rewriting `[rec_20260701_malak]` |

## Named frameworks

| Name | What it is |
|---|---|
| **Kellen's five lenses** | The review structure he applies to a full teardown: **motivation** (functional vs strategic vs emotional layer), **targeting** (market + persona + angle, not just firmographics), **skepticism** (is certainty being forced?), **proof** (does it map to their situation?), **CTA** (does it match buyer readiness?) `[rec_20260629_ali_qureshi]` |
| **MMF skill / "Kellen skill"** | Ihor Seheda's LLM-assisted scoring rubric built to imitate Kellen's review. Scores Market clarity, Segment meaningfulness, Persona in context, Angle sharpness, Belief & signal fit, and Testability out of 5, then names the single "primary bottleneck" `[rec_20260729_tim_keen]`, `[rec_20260615_muhammad_abbas]` |
| **BAR** | Background, Action, Results — an old interviewing framework Will Allred repurposes for long-form emails: build a look-alike customer story from work history + company stage + triggers `[rec_20260708_sharad]` |
| **WIIFM** | "What's In It For Me" — John Kitsmiller's rule that in multi-stakeholder deals you must answer it for every persona `[rec_20260604_ben_aperoadvisors_com]` |
| **I:you ratio** | Attributed to Josh Braun: count first-person vs second-person references and cut the former `[rec_20260730_abhi_at_gtmcafe]` |
| **Sell the destination, not the vehicle** | Adnan Manna — pitch the outcome, not the mechanism's cleverness. "Unless the vehicle is a Rolls Royce" `[rec_20260712_varun_y]` |

## Practitioners cited as authorities

Referenced as reference points rather than participants.

- **Will Allred** — participant; cites Lavender's dataset on length, clarity and formality. The channel's brevity anchor at ~75 words.
- **Nick Abraham** — cited for very short copy and for outbound offer design.
- **Josh Braun** — cited for the I:you ratio and "you" framing.
- **Lavender** — the email-coaching tool whose data Will Allred quotes.

## Tooling shorthand

| Term | Meaning |
|---|---|
| **SL** | Subject line |
| **Clay / Clay line / Claygent** | Clay, the GTM data tool; a "Clay line" is a personalization line generated from enriched data; Claygent is its agentic research feature |
| **spintax** | `{Hey\|Hi\|Hello}` syntax that randomises wording across sends to vary fingerprints |
| **DFY** | Done-for-you (as opposed to advisory or coaching) |
| **inbox rotation** | Spreading sends across many mailboxes to protect deliverability |
| **Exa / Exa Agent** | Search/retrieval tool used for sourcing accounts and contacts |
| **NPI Registry** | Public US healthcare provider database, recommended for sourcing medical contacts `[rec_20260729_will_allred]` |
| **Smartlead / Mailmeteor** | Cold email sending platforms; Mailmeteor's spam-word flagging came up as over-cautious `[rec_20260728_ivan]` |
| **Gorgias / Klaviyo / Zoho** | Vertical SaaS products that appear as the subject of copy under review, not as channel tools |
| **TAM / ICP** | Total addressable market / ideal customer profile |
| **CAN-SPAM** | US commercial email law; the channel's practical read is include an address and a plain opt-out `[rec_20260619_bharat]` |
